# claude-skills

Personal Claude Code slash commands. Each `.md` file in this repo maps to a `/command` you can invoke in any Claude Code session.

## Installation

Copy any skill file to `~/.claude/commands/`:

```bash
cp vc-radar.md ~/.claude/commands/
```

Then invoke it in Claude Code as `/vc-radar`.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| [vc-radar](vc-radar.md) | `/vc-radar` | Track VC & angel investor signals. Surfaces emerging startup opportunities before consensus. Supports quick scan, full sweep, focused deep-dives, and persistent logging. |
